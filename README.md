# ijzm-qol
QOL Datapack for Minecraft 26.3

## ⚡ Quick Start
1. Download [latest release](https://github.com/ijzm/ijzm-qol/releases/latest)
2. Unzip in your world's datapacks folder
3. Restart the world or `/reload` 

## 🛠️ Changes
- Fast chest recipe
- Fast stick recipe
- Fast hopper recipe
- Log stripping on
